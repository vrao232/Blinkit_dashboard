# 🟢 Blinkit Sales Performance Dashboard | Power BI

## 📊 Project Overview
This project presents an interactive Power BI dashboard that provides a comprehensive analysis of Blinkit’s sales, customer ratings, and outlet performance.  
The goal is to uncover actionable insights that help optimize operations, improve customer satisfaction, and drive sales growth through data-driven decision-making.

---

## 🎯 Objectives
- Analyze sales performance across outlets, cities, and product categories.  
- Identify trends in delivery time, customer feedback, and order volume.  
- Evaluate correlations between customer satisfaction and sales growth.  
- Create an intuitive dashboard for management to monitor KPIs in real time.

---

## 🧠 Key Insights
- **Top Outlets:** Highlighted top-performing outlets by revenue and rating.  
- **Delivery Efficiency:** Analyzed average delivery times to detect bottlenecks.  
- **Category Contribution:** Visualized sales contribution of various product categories.  
- **Customer Satisfaction:** Correlated customer ratings with delivery performance and product mix.

---

## 🧩 Tools & Techniques
- **Power BI:** Data modeling, DAX measures, and dashboard creation.  
- **Excel / CSV:** Used as data source for cleaning and preprocessing.  
- **DAX Functions:** Applied calculated columns and measures for KPIs.  
- **Data Visualization:** Interactive charts, slicers, and drill-through analysis.

---

## 📈 Dashboard Features
- Dynamic filters for outlet size and type, and food type.  
- KPI cards for total sales, average rating, and delivery time.  
- Trend charts showing monthly and category-wise sales performance.  
- Insightful visuals for management reporting and decision-making.
